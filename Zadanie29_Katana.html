Zadanie 29 – Pytania teoretyczne z JavaScript

1. Jakie są dwa sposoby definiowania właściwości obiektu w JavaScript?

Pierwszy sposób:
obiekt.nazwaWłaściwości = wartość;
Przykłady:
samochód.marka = "Opel Omega";
samochód.rok = 1996;
samochód.cena = 25000;

Drugi sposób:
obiekt["nazwaWłaściwości"] = wartość;
Przykład:
samochód["cena"] = 25000;

2. Jak odwoływać się do właściwości i metod obiektu?

Do właściwości i metod obiektu odwołujemy się za pomocą notacji kropkowej, podając nazwę obiektu, kropkę i nazwę właściwości lub metody, na przykład:
console.log(samochód.kolor);

3. Czym charakteryzuje się konstruktor?

  • Jest automatycznie wywoływany podczas tworzenia nowego obiektu.
  • Ma taką samą nazwę jak klasa.
  • Nie zwraca żadnej wartości.
  • Może przyjmować argumenty.

4. Przykład tworzenia obiektu

var osoba = {
  nazwisko: "Kowalski",
  imię: "Jan",
  zawód: "piekarz",
  wyświetl: function() {
    document.write(this.nazwisko + " " + this.imię);
  }
}

5. Jakie jest znaczenie słowa kluczowego 'this' i jak oddzielamy elementy obiektu?

Słowo kluczowe this odnosi się do bieżącego obiektu, umożliwiając dostęp do jego pól i metod wewnątrz obiektu.
Pola i metody w obiekcie oddzielamy od siebie przecinkami.

6. Przykład konstruktora w JavaScript

function Klient(nazwisko, imię, zawód) {
  this.nazwisko = nazwisko;
  this.imię = imię;
  this.zawód = zawód;
  this.wypisz = function() {
    alert(this.nazwisko + " " + this.imię);
  }
}

7. Do czego służy słowo kluczowe 'new'?

Słowo kluczowe new wykorzystuje się do tworzenia nowej instancji obiektu na podstawie konstruktora.
Przykład: 

var osoba1 = new Klient("Kowalski", "Jan", "kierowca");
var osoba2 = new Klient("Nowak", "Anna", "sekretarka");

8. Jakie jest znaczenie słowa kluczowego 'prototype'?

Słowo kluczowe prototype umożliwia rozszerzanie konstruktorów o nowe metody i właściwości.
Wszystkie obiekty utworzone za pomocą tego konstruktora będą dziedziczyć dodane właściwości i metody.

function Klient() {
  this.nazwisko = "Bielski";
  this.imię = "Paweł";
}
Klient.prototype.piszDane = function() {
  document.write(this.nazwisko + " " + this.imię);
}
Klient.prototype.zawód = "kierowca";
var osoba1 = new Klient();
osoba1.piszDane();
